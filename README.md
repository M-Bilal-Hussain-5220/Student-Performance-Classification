# Student Performance Classification
## Description
This is a basic Machine Learning project developed using Python. The project uses the K-Nearest Neighbors (KNN) algorithm to classify student results based on study hours, attendance, and assignments.
## Features
* Loads student data using Pandas
* Explores the dataset
* Splits data into training and testing sets
* Trains a KNN classification model
* Predicts student results
* Calculates model accuracy
* Displays a histogram of study hours
## Technologies Used
* Python
* Pandas
* Scikit-learn
* Matplotlib
* K-Nearest Neighbors (KNN)
## How to Run
Install the required libraries:

```bash
pip install pandas scikit-learn matplotlib
```

Then run:

```bash
python student_performance.py
```

* `student_performance.py` — Python machine learning code
